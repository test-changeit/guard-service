## Introduction

A package to be used as network api provider for @alakipalaki/bitcoin package

## Installation

npm:

```sh
npm i @alakipalaki/bitcoin-esplora
```

yarn:

```sh
yarn add @alakipalaki/bitcoin-esplora
```
