## Table of contents

## Introduction

A package to be used as network api provider for any OP-Stack based chains that are built on the @alakipalaki/evm package

## Installation

npm:

```sh
npm i @alakipalaki/evm-op-stack-rpc
```

yarn:

```sh
yarn add @alakipalaki/evm-op-stack-rpc
```
