# @alakipalaki/firo

## Description

This package implements the Firo chain interface for the Rosen bridge. It provides functionality for handling Firo blockchain operations including transaction creation, signing, and validation.

## Installation

```bash
npm install @alakipalaki/firo
```

## Development

This package is part of the Rosen bridge ecosystem and follows Bitcoin-based UTXO patterns, similar to the Doge chain implementation.
